# Roadmap

## Phase 0 — Foundation (current)

**Outcome:** independent, documented project boundary and a small reversible architecture.

- repository and core documents;
- decision log, security notes and compliance notes;
- initial competitor research, ICP and discovery framework.

## Phase 1 — Validate the workflow before broad build

**Outcome:** evidence from 15–20 non-leading interviews about frequency, pain, data availability and willingness to test.

**Exit criteria:** a segment/workflow is prioritised based on recorded evidence; no customer claims are fabricated.

## Phase 2 — Synthetic, deterministic core demo

**Outcome:** controlled NOVA INDUSTRIES workbooks produce correct, traceable validation and variance outputs.

**Exit criteria:** injected anomalies are rediscovered; test suite passes; conclusions expose source rows.

## Phase 3 — Usable local demo

**Outcome:** a controller can upload three workbooks, inspect findings and provide structured feedback within five minutes.

**Exit criteria:** user test shows the output is understandable; no external service or real data required.

## Phase 4 — Design-partner readiness (not authorised/started)

**Outcome:** a scoped, secure real-data pilot proposal only after legal/privacy/security and commercial approval.

**Exit criteria:** explicit founder approval plus documented data handling, deployment and customer terms.

## Non-goals until evidence changes the order

SAP integrations, multi-tenancy, broad agents, forecasting, autonomous workflows, public deployment and billing.
