# Public Portfolio Safety Checklist

Before every public commit or push:

- [ ] Run the test suite.
- [ ] Check staged files and diff for data/credential leakage.
- [ ] Confirm only synthetic, public or explicitly authorised material is included.
- [ ] Do not add `.env`, tokens, keys, employer material, client data or internal screenshots.
- [ ] State limitations honestly; do not imply production readiness, compliance or customer validation.
- [ ] Do not fabricate contribution history, customer interviews, metrics or adoption.

This checklist is intentionally part of the public project record.
