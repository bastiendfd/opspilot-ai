# Customer Discovery

## Rules

- Do not fabricate interviews, quotes, pain scores, willingness to pay or customer evidence.
- Do not lead interviewees toward OpsPilot or show the solution before understanding the current workflow.
- Do not contact anyone, send invitations or use employer/customer contact data without Bastien’s explicit approval.
- Record consent and anonymise where appropriate.

## Interview record template

Create one dated Markdown file per real interview with:

```markdown
# Interview — YYYY-MM-DD — [anonymised ID]

## Metadata
- Company type / sector:
- Employee range:
- Country:
- Role:
- Relationship / recruitment channel:
- Consent / anonymisation:

## Current workflow
- Reporting cadence:
- Systems and files:
- Participants / handoffs:
- Process steps:
- Current workaround:

## Pain and consequences
- Longest step:
- Error / delay points:
- Hours involved (quote/context):
- Financial or operational consequence:
- Existing tools / prior automation attempts:

## Buying and testing signals
- Stakeholders / budget owner:
- Security / data concerns:
- Would test? Exact wording:
- Willingness to pay? Exact wording and context:

## Evidence
- Direct quotes:
- Researcher observations (clearly separate):
- Follow-up questions:
```

## Synthesis fields

Track patterns only after multiple interviews: recurring workflow, system stack, frequency, time burden, cost of delay/error, evidence of value, objections and disconfirming signals.
