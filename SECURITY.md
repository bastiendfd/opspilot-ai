# Security Policy

## Scope

OpsPilot AI is a **local, synthetic-data MVP**. It is not security-certified, production-ready or approved for employer/customer data.

## Do not upload

Never use this repository or local demo with:

- employer, customer, supplier or partner data;
- personal data or confidential business information;
- credentials, API keys, tokens, connection strings or private keys;
- internal ERP, BI, SharePoint, email or document exports.

## Reporting a security issue

Do not publish sensitive details in a public GitHub issue. Use GitHub’s private security-advisory mechanism for the repository once enabled, or contact the repository owner privately through GitHub.

## Current security limitations

The MVP has no authentication, tenant isolation, encryption-at-rest design, retention policy, production audit logging or hostile-file hardening. It must remain local and synthetic until those controls are designed and reviewed.
